# Contributing

Keep the core easy to run, honest about what is generated, and delightful in the browser.

1. Open an issue describing the user problem and a concrete example.
2. Make a focused change. Prefer native browser features over new runtime dependencies.
3. Run `npm test` and `npm run build` on Node 20.6+.
4. Check the affected scene in Chinese and English, desktop and mobile, all three themes.
5. Include before/after screenshots for visual changes and exact reproduction steps for bugs.

Good contributions include original topic packs, stronger typography, browser export fixes, and documented provider adapters. Never commit credentials, private datasets, copyrighted keynote collections, or images without a clear permission basis. Do not represent the project as endorsed by any company.
