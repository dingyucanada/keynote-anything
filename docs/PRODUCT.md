# Keynote Anything

A product studio that turns an ordinary object or real product into an editable, cinematic keynote. The first useful result must be available without an account, model endpoint or API key.

## Product promise

Input a thing. Get a story worth presenting. Edit it. Take it with you.

Core loop: brief → generated storyboard → edit scene → rehearse/play → portable HTML or poster → remix.

## Audience

- Curious creators: absurdly serious launches for ordinary objects.
- Founders and marketers: a structured first draft for a real launch.
- Technical storytellers and ecosystem teams: reveal, architecture and narrative pacing without a slide-design learning curve.

## Scope

Seven scene types: hook, problem, reveal, architecture, benefits, one-more-thing, closing. Three tones, three visual themes, English and Chinese. Deterministic local director plus optional server-side OpenAI-compatible model adapter. Uploaded product image, scene-level editing, notes, undo/redo, local save, JSON import/export, standalone HTML, PNG poster and print layout.

No API key in browser storage. No implicit telemetry. No simulated generation delays. Local mode is labeled as a template-based director, not a model call. Conceptual stats are not represented as measurements. No impersonation of a named executive or official NVIDIA branding.

## Visual direction

Creator studio: warm ivory surrounding a deep-black stage; restrained persimmon accent; large editorial type; filmstrip storyboard; scene-specific composition and reveals.

## Quality bar

The entire creation/edit/play/export/import loop must work. Empty, long, hostile and malformed inputs must be handled. Content survives refresh; local-storage failure is visible. Imported/generated objects are validated before rendering. Fullscreen can fall back to presentation mode. Reduced motion is respected. Exported HTML must operate offline without the app server.
